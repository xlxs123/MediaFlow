## 使用和限制

解压完整应用 ZIP，运行 `MediaFlow.exe`，点击主窗口顶部“更新与版本管理”。首次从未配置的旧客户端采用正式渠道时，先运行 2.1.0；以后按已固定的稳定清单检查。部署、健康检查和启动是分开的确认操作，旧文件夹保留。

- Ed25519 验证更新发布身份；本版没有 Windows Authenticode 签名，不能把两者混同。
- 5 个历史网站媒体只做离线媒体回归；没有重下全部网站样本，也不声称本轮重新验证了网站登录状态。
- 已签名 ZIP 中保留的部分历史文档描述旧版本未配置状态；当前渠道以实际内置信任配置、`PRODUCTION_RELEASE.md` 和本报告为准。源码仓库的旧文档状态已修正，未为文档重写或覆盖已发布资产。
- 私钥保险目录受 Windows 用户 DPAPI 保护；换用户、重装或丢失用户恢复资料可能无法再签名，应由发布者独立妥善备份。
- 无自动快捷方式切换、差量更新或 ARM64 版本；回退应用不回退用户数据库。对应第三方源码提供真实材料及上游构建辅助版本限制，不承诺逐字节复现。
